# AI_RADIO Releases

This public repository contains AI_RADIO installers and in-app update feed assets only. Application source is maintained separately.

## Download and install

1. Open [Releases](https://github.com/Avalanche110/AI_Radio-Releases/releases).
2. Expand **Assets** for the newest beta.
3. Download `AI_RADIO-Desktop-beta-Setup.exe`.
4. Do not download GitHub's automatically generated **Source code** archives; they are not the application installer.
5. Compare the installer with the release's `SHA256SUMS.txt` before running it.

Installed AI_RADIO 0.9.2 and later use the `releases.beta.json` and full `.nupkg` assets in this repository for operator-initiated in-app updates.

The current beta binaries are unsigned, so Windows SmartScreen may show an unknown-publisher warning.
